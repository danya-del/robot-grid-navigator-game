# robot-grid-navigator-game
An interactive command-line Python game where a robot (`R`) spawns randomly on a 2D grid, avoids outer walls (`x`), and navigates to reach a randomly placed goal (`G`).

## Features
- Random spawn generation for both the robot (`R`) and the goal (`G`)
- Live `(x, y)` coordinate tracking and grid rendering
- Wall collision detection and win-state handling

## How to Run
```bash
python3 navigator.py
```
